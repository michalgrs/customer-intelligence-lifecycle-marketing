# Wizualizacje

`segment-value.svg` porównuje udział każdego segmentu w kupujących i w revenue, na wspólnej skali procentowej. Dane przedstawiają finalne wyniki segmentacji po cleanupie revenue z analizy pełnego datasetu REES46 Cosmetics wykonanej w Google BigQuery Sandbox. Data odniesienia Recency: 2020-02-29.

Wykres pokazuje koncentrację historycznej wartości, a nie skuteczność kampanii, prognozę przychodu ani LTV. Bazą udziału klientów jest 110,518 buyers. Revenue jest miarą dodatniej wartości purchase zgodnie z opisaną metodologią; udziały są zaokrąglone.

Format SVG umożliwia wyświetlanie bez dodatkowego oprogramowania na GitHubie i zachowuje czytelność przy powiększeniu. Nie dodano fikcyjnych dashboardów kampanii ani wykresów wyników eksperymentów.
